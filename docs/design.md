# Salary — Design System

> Документ описывает визуальный язык приложения **Salary** (персональный финансовый аналитик).
> Составлен на основе ответов на 10 вопросов по дизайну.

## 0. Итоги опроса

| #   | Вопрос           | Выбор                                                                                    |
| --- | ---------------- | ---------------------------------------------------------------------------------------- |
| 1   | Визуальный стиль | **Glassmorphism** — полупрозрачные «стеклянные» карточки с размытием на градиентном фоне |
| 2   | Цветовая тема    | **Светлая + тёмная**, переключатель, по умолчанию — системная                            |
| 3   | Акцентный цвет   | **Изумрудно-зелёный** (доходы/рост), расходы — коралловый                                |
| 4   | Шрифт            | **Inter** (с `font-variant-numeric: tabular-nums` для сумм)                              |
| 5   | Навигация        | **Сайдбар** на десктопе + **нижний таббар** на мобильных                                 |
| 6   | Главный график   | **Линия / область** — динамика баланса, доходов и расходов во времени                    |
| 7   | Плотность        | **Комфортная**                                                                           |
| 8   | Скругления       | **Сильные**: 16–24px                                                                     |
| 9   | Иконки категорий | **Линейные иконки Lucide в цветном круге**                                               |
| 10  | Анимации         | **Сдержанные**: 150–300 мс, плавные переходы, анимация появления графиков                |

---

## 1. Принципы

1. **Цифры — главные.** Стекло и градиенты — фон, а не содержание. Суммы всегда самый контрастный элемент на карточке.
2. **Зелёный = пришло, коралловый = ушло.** Это правило не нарушается нигде: ни в графиках, ни в бейджах, ни в иконках.
3. **Читаемость поверх эффектов.** Размытие и прозрачность никогда не опускают контраст текста ниже WCAG AA (4.5:1 для текста, 3:1 для крупных цифр и графических элементов).
4. **Спокойствие.** Финансы вызывают тревогу — интерфейс должен успокаивать: мягкие формы, плавные движения, никаких мигающих красных тревог.

## 3. Типографика

- **Шрифт:** Inter (через `next/font/google`, subsets: `latin`, `cyrillic`), fallback: `system-ui, sans-serif`.
- **Все суммы и проценты:** `tabular-nums` (цифры одинаковой ширины — колонки не «прыгают»).

| Роль                         | Размер / Line-height                    | Вес | Пример                      |
| ---------------------------- | --------------------------------------- | --- | --------------------------- |
| Display (баланс на дашборде) | 40/48 (моб. 32/40)                      | 700 | `124 350 ₽`                 |
| H1 (заголовок страницы)      | 28/36                                   | 700 | «Аналитика»                 |
| H2 (заголовок карточки)      | 18/26                                   | 600 | «Расходы по категориям»     |
| Body                         | 15/24                                   | 400 | Текст, ячейки таблиц        |
| Body-strong                  | 15/24                                   | 600 | Суммы в списках             |
| Caption                      | 13/18                                   | 500 | Подписи, даты, оси графиков |
| Overline                     | 12/16, uppercase, letter-spacing 0.04em | 600 | «ДОХОД ЗА МЕСЯЦ»            |

**Формат денег:** `Intl.NumberFormat('ru-RU', { style: 'currency', currency })` → `124 350,00 ₽`. Знак: доход `+12 000 ₽` (зелёный), расход `−3 450 ₽` (коралловый, настоящий минус `−`, а не дефис).

## 4. Сетка, отступы, плотность

- **Шаг сетки:** 4px. Используемые отступы: 4, 8, 12, 16, 20, 24, 32, 40, 48.
- **Плотность — комфортная:**
  - padding карточки: 20px (моб. 16px)
  - gap между карточками: 20px (моб. 12px)
  - высота строки в списке операций: 56px
  - высота инпутов и кнопок: 44px (кликабельная зона ≥ 44×44)
- **Контейнер контента:** max-width 1280px, боковые поля 32px (моб. 16px).
- **Брейкпоинты (Tailwind):** `sm 640`, `md 768`, `lg 1024`, `xl 1280`.
- **Сетка дашборда:**
  - `xl`: 12 колонок — 4 KPI-карточки по 3 колонки; главный график 8 колонок + донат 4.
  - `md`: 2 колонки KPI, графики на всю ширину.
  - `< md`: всё в одну колонку, KPI — горизонтальный скролл-слайдер.

## 5. Форма и глубина

| Токен           | Значение | Где                                    |
| --------------- | -------- | -------------------------------------- |
| `--radius-sm`   | 12px     | Инпуты, бейджи, мелкие кнопки          |
| `--radius-md`   | 16px     | Кнопки, элементы списков               |
| `--radius-lg`   | 24px     | Карточки, модалки, сайдбар             |
| `--radius-full` | 9999px   | Аватар, иконки категорий, чипы-фильтры |

**Стеклянная карточка (`.glass-card`):**

```css
.glass-card {
  background: var(--glass);
  backdrop-filter: blur(16px) saturate(160%);
  -webkit-backdrop-filter: blur(16px) saturate(160%);
  border: 1px solid var(--glass-border);
  border-radius: var(--radius-lg);
  box-shadow: 0 8px 32px rgba(15, 23, 42, 0.08); /* dark: rgba(0,0,0,0.35) */
}
```

**Фолбэк:** если `backdrop-filter` не поддерживается или включено `prefers-reduced-transparency` — карточки становятся непрозрачными (`--glass-strong` с alpha 0.95).

## 6. Навигация

### Десктоп (`≥ lg`): сайдбар

- Ширина 256px, стеклянная панель с отступом 16px от краёв экрана (плавающая), radius 24px.
- Сверху: логотип **Salary** (иконка `Wallet` в изумрудном круге + текст).
- Пункты: **Дашборд** (`LayoutDashboard`), **Операции** (`ArrowLeftRight`), **Категории** (`Tags`), **Аналитика** (`ChartLine`), **Бюджеты** (`PiggyBank`), **Настройки** (`Settings`).
- Активный пункт: фон `primary/12%`, текст и иконка `primary`, слева полоска 3px.
- Снизу: переключатель темы, аватар + имя пользователя.

### Планшет (`md–lg`)

- Сайдбар сворачивается до 80px (только иконки, тултипы при наведении).

### Мобильные (`< md`): нижний таббар

- Высота 64px + `safe-area-inset-bottom`, стеклянный, прилипает к низу.
- 5 элементов: Дашборд · Операции · **[+]** · Аналитика · Ещё.
- Центральная кнопка **[+]** — круглая 56px, `primary`, приподнята на 12px; открывает bottom-sheet «Добавить операцию».
- «Ещё» открывает лист: Категории, Бюджеты, Настройки.

### Шапка страницы (все размеры)

- Заголовок H1 + селектор периода (`Месяц ▾`, стрелки ← → для переключения) + кнопка «Добавить» (десктоп).

## 7. Компоненты

### 7.1 KPI-карточка

```
┌──────────────────────────┐
│ ДОХОД ЗА МЕСЯЦ    (↗ icon)│  ← overline + иконка в круге income/12%
│ 185 000 ₽                │  ← display, tabular-nums
│ ▲ 12% к прошлому месяцу  │  ← caption, зелёный / коралловый
│ ╱╲_╱‾╲_  (sparkline)     │  ← мини-график 32px, без осей
└──────────────────────────┘
```

4 карточки: **Баланс**, **Доходы**, **Расходы**, **Норма сбережений (%)**.

### 7.2 Иконка категории

- Круг 40px (в списках) / 32px (в чипах), фон — цвет категории с прозрачностью 15% (dark: 20%), иконка Lucide 20px, stroke 2, цвет категории.

### 7.3 Строка операции

```
(🛒)  Продукты               −2 340 ₽
      Пятёрочка · 14 ноя         Карта
```

Иконка категории · название категории (body-strong) · комментарий + дата (caption) · сумма справа (body-strong, цвет по типу) · счёт (caption). Свайп влево на мобильном → «Удалить» / «Изменить».

### 7.4 Кнопки

| Вариант     | Вид                                                    |
| ----------- | ------------------------------------------------------ |
| Primary     | Заливка `--primary`, текст белый, radius 16, высота 44 |
| Secondary   | `--glass` + бордер `--glass-border`                    |
| Ghost       | Прозрачный, hover: `foreground/6%`                     |
| Destructive | Заливка `--expense`                                    |

### 7.5 Поля ввода

- Высота 44, radius 12, фон `--glass-strong`, бордер 1px `--glass-border`, фокус — ring 2px `--ring` + offset 2px.
- Поле суммы: крупный шрифт 28px, tabular-nums, автоформатирование пробелами (`12 500`).
- Переключатель «Расход / Доход» — сегментированный контрол (pill), активный сегмент окрашен в `--expense` / `--income`.

### 7.6 Модалки и bottom-sheet

- Десктоп: модалка по центру, max-width 480px, `--glass-strong`, radius 24, overlay `rgba(0,0,0,0.3)` + blur 4px.
- Мобильный: bottom-sheet со «ручкой» сверху, radius 24 только сверху, закрытие свайпом вниз.

### 7.7 Пустые состояния

Иконка 48px в круге `primary/12%` + заголовок + одна строка пояснения + primary-кнопка. Пример: «Пока нет операций — добавьте первую, и здесь появится аналитика».

### 7.8 Тосты

Правый нижний угол (моб. — сверху), стекло, 4 сек. «Операция удалена · **Отменить**».

## 8. Графики (Recharts)

**Главный тип — линия/область.** Остальные типы — вспомогательные, на странице «Аналитика».

### 8.1 Главный график дашборда — «Динамика»

- `AreaChart`, высота 320px (моб. 220px).
- Две серии: **Доходы** (`--income`) и **Расходы** (`--expense`), линия 2.5px, `type="monotone"`.
- Заливка под линией: вертикальный градиент цвета серии от 30% до 0% прозрачности.
- Переключатель серий над графиком: чипы «Доходы / Расходы / Баланс». Режим «Баланс» — одна линия накопленного остатка (`--primary`).
- Сетка: только горизонтальные линии, пунктир `3 3`, цвет `foreground/8%`.
- Оси: без линии оси, подписи caption `--muted-foreground`; Y — сокращённо (`120к`, `1,2м`).
- Тултип: стеклянная карточка, дата + обе суммы + разница.
- Активная точка: круг 6px с белым обводом 2px.

### 8.2 Вспомогательные

| График                   | Где                         | Детали                                                                                           |
| ------------------------ | --------------------------- | ------------------------------------------------------------------------------------------------ |
| Sparkline                | KPI-карточки                | `LineChart` 32px высотой, без осей и тултипа                                                     |
| Донат по категориям      | Дашборд (справа), Аналитика | Внутренний радиус 70%, в центре — сумма; сегменты — цвета категорий; padding между сегментами 2° |
| Столбцы «месяц к месяцу» | Аналитика                   | Сгруппированные столбцы доход/расход, radius верхних углов 6px                                   |
| Топ категорий            | Аналитика                   | Горизонтальные прогресс-бары с иконкой и %                                                       |
| Бюджет                   | Бюджеты                     | Прогресс-бар: < 80% primary, 80–100% warning, > 100% expense                                     |

### 8.3 Общие правила графиков

- Никаких 3D, теней на сегментах и «радуг» — максимум 8 цветов, остальное в «Прочее».
- Всегда есть текстовая альтернатива: под графиком таблица-легенда со значениями (доступность + точность).
- Пустые данные — заглушка «Недостаточно данных за период» вместо пустых осей.

## 9. Анимации (сдержанные)

| Что                    | Как                                                              | Длительность / easing                   |
| ---------------------- | ---------------------------------------------------------------- | --------------------------------------- |
| Hover карточки         | `translateY(-2px)` + усиление тени                               | 150ms, ease-out                         |
| Нажатие кнопки         | `scale(0.97)`                                                    | 100ms                                   |
| Появление страницы     | fade + `translateY(8px → 0)`, карточки по очереди (stagger 40ms) | 250ms, `cubic-bezier(0.2, 0.8, 0.2, 1)` |
| Графики                | Отрисовка линии/роста столбцов при первом появлении              | 600ms, ease-out                         |
| Счётчик сумм в KPI     | Count-up от предыдущего значения                                 | 500ms                                   |
| Модалка / bottom-sheet | fade + scale 0.96→1 / slide-up                                   | 200ms                                   |
| Переключение темы      | Плавная смена цветов `transition: background-color, color`       | 200ms                                   |

**`prefers-reduced-motion: reduce`** — все анимации движения отключаются, остаются только мгновенные смены состояния.

Библиотека: `motion` (Framer Motion) для появления/модалок; CSS-transitions для hover.

## 11. Доступность

- Контраст текста ≥ 4.5:1 на стекле **с учётом худшего места фона** (проверять на самом ярком пятне градиента).
- Цвет никогда не единственный носитель смысла: у сумм есть знак `+`/`−`, у трендов — стрелки ▲▼.
- Видимый фокус (`focus-visible` ring) на всех интерактивных элементах.
- Все иконки-кнопки имеют `aria-label`.
- Графики: `role="img"` + `aria-label` с кратким выводом («Расходы за ноябрь выросли на 12%») + таблица-легенда.
- Поддержка `prefers-reduced-motion` и `prefers-reduced-transparency`.

## 13. Уточнения после проверки (валидатор палитры и axe)

- **Цвета графиков** — отдельные токены, не совпадают с цветами текста:
  `--chart-income` `#047857` / `#059669` (dark), `--chart-expense` `#FB7185` / `#F43F5E` (dark), `--chart-balance` `#0284C7` / `#38BDF8`.
  Пара доход/расход разведена по светлоте: ΔE 10.6 при дейтеранопии (светлая тема), все проверки пройдены в тёмной.
- **Тёмная палитра категорий** — шаги 500–600 (`#059669, #0284C7, #8B5CF6, #D97706, #F43F5E, #0D9488, #6366F1, #EA580C`): светлота 0.48–0.67 и контраст ≥ 3:1 к тёмной поверхности.
- **Текст на цветных кнопках**: `--income-foreground` / `--expense-foreground` — в тёмной теме тёмный текст на светлом коралловом (белый давал 2.7:1).
- **Тосты** на мобильном — сверху (снизу перекрывали таббар и кнопку «+»).
- **Автофокус** в формах — только на устройствах с мышью: на телефоне клавиатура перекрывала шторку.
